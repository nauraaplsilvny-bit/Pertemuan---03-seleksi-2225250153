## Struktur Program

Program latihan terdiri dari:
1. Menentukan bilangan genap atau ganjil.
2. Membandingkan dua bilangan.
3. Menentukan kelulusan berdasarkan nilai dan kehadiran.
4. Menentukan jenis segitiga.
5. Menganalisis persamaan kuadrat.

## Cara Menjalankan

Contoh:

python latihan/02_bandingkan_dua_bilangan.py

python latihan/03_kelulusan_bersyarat.py

python latihan/04_jenis_segitiga.py

python tugas/analisis_persamaan_kuadrat.py

## Algoritma Tugas

1. Masukkan nilai a, b, dan c.
2. Periksa apakah a sama dengan 0.
3. Jika a = 0, tampilkan bahwa bukan persamaan kuadrat.
4. Jika a tidak sama dengan 0, hitung diskriminan.
5. Jika D > 0, hitung dua akar real.
6. Jika D = 0, hitung akar real kembar.
7. Jika D < 0, tampilkan bahwa tidak ada akar real.

## Hasil Pengujian

| Input | Hasil |
|---|---|
| a=1, b=-5, c=6 | Dua akar real |
| a=1, b=2, c=1 | Akar real kembar |
| a=1, b=0, c=1 | Tidak ada akar real |
| a=0, b=2, c=3 | Bukan persamaan kuadrat |
